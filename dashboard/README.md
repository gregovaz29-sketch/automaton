# Dashboard local seguro

Abre `dashboard/index.html` directamente en el navegador.

El panel solo genera propuestas de prueba y guarda su registro en el almacenamiento del navegador. No se conecta a Automaton, no usa red, no lee archivos, no crea wallet ni ejecuta pagos.

La conexión real se añadirá únicamente mediante un gateway local con permisos explícitos.
